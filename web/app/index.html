Скачать APK
  • 1Нажмите «Скачать APK» и дождитесь загрузки файла.
  • 2Откройте скачанный файл. Android попросит разрешить установку из этого источника — нажмите «Настройки» и включите разрешение для браузера.
  • 3Вернитесь назад и нажмите «Установить».
  • 4Откройте SplitHub и войдите по номеру телефона.
Только для клиентов SplitHub.
Вопросы по установке — splithub.ru
