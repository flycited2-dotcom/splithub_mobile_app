# ТЗ: синхронизация приложения с сайтом — смета, кнопки, стили (ноябрь 2026)

Дата: 04.11.2026 · Ветка приложения: `claude/site-parity-catalog-guest-orders`
Эталон — сайт splithub.ru, PR [flycited2-dotcom/splithub#4](https://github.com/flycited2-dotcom/splithub/pull/4)
(файлы `estimate.js` — вся смета, `index.html` — баннер, кнопка «Наверх», шапка).

Цель: приложение и мобильная версия сайта выглядят и работают **одинаково** — те же кнопки,
цвета, тексты и функции сметы. Где на сайте что-то сделано «по-браузерному» из-за ограничений
браузеров, в приложении делаем нативно (это отмечено ниже).

---

## Часть 1. Что сделано на сайте (03–04.11.2026)

1. **Смета для клиента на сайте** — перенесена из приложения (`fe10a9d`) и доработана:
   - вход: **баннер на главной** и **плашка в шторке заявки**, обе в стиле Max (сине-фиолетовые);
   - своя техника в смете: **поиск по каталогу** прямо в смете, ±/удаление, «Добавить из заявки (N поз.)»,
     при открытии из заявки позиции подставляются сами;
   - наценка 0/15/20/25/30% или своя, цена клиенту = опт × (1 + %), **округление вверх до 10 ₽**,
     опт в документы не попадает, «ваша наценка» видна только монтажнику;
   - работы: 5 типовых (как в приложении) + свои; свои можно удалить (✕);
   - исполнитель/телефон, клиент/адрес.
2. **Отправка клиенту сразу файлом PDF** через системное «Поделиться» (Telegram, WhatsApp, Max, почта).
   PDF собирается заранее, пока заполняют смету, — иначе браузер не открывает меню.
   - Samsung Internet **не отдаёт PDF** в «Поделиться» (проверено на телефоне: PNG/текст проходят,
     любой PDF — `NotAllowedError`). Там смета уходит **картинкой PNG** (страница PDF, обрезан пустой низ).
     **В приложении это не нужно** — нативный шаринг (expo-sharing) отдаёт PDF без ограничений.
3. **Скачать PDF** (красная кнопка) и **Скачать Excel** (зелёная). Excel оформлен: высоты строк,
   цветные плашки исполнителя и клиента, формулы с готовыми значениями.
4. **Смета не «вечная»**: техника живёт, пока открыт сайт (как заявка). Запоминаются только настройки
   монтажника: наценка, цены и названия работ, свои работы, имя и телефон. Количества работ в новой
   смете — типовые: монтаж ×1, остальное 0.
5. **Стили сайта**: насыщенный зелёный баннер «Установите приложение» вместо бледного стекла;
   круглая кнопка **«Наверх»** (стрелка + подпись внутри, синий контур); убрана кнопка «Поделиться сайтом».
6. **Баг шапки**: на телефоне «Заявка» уезжала за край экрана (кнопка «Войти» была шириной 168 px
   из-за перебитого CSS). Исправлено: «Войти» занимает остаток места и сокращается многоточием.

Что пробовали и **не переносим**: отправку ссылкой на файл через сервер (`api/estimate.php`) —
удалена, владелец решил отправлять сразу файлом.

## Часть 2. Что сделать в приложении

Токены цветов (как на сайте):

| Токен | Значение | Где |
|---|---|---|
| `max` | градиент 135° `#2A7FFF → #5B5BFF (50%) → #8A3FFC` | баннер/плашка сметы (кнопка), «Отправить клиенту» |
| `maxTint` | фон `rgba(42,127,255,0.20) → rgba(124,77,255,0.16)`, контур 1.5 px `rgba(98,90,255,0.6)` | фон баннера/плашки сметы |
| `pdf` | `#F0443A → #D93025` (сверху вниз), тень `rgba(217,48,37,0.35)` | «Скачать PDF» |
| `excel` | `#21A366 → #107C41`, тень `rgba(16,124,65,0.35)` | «Скачать Excel» |
| `up` | контур 2 px `#2A7FFF`, текст/иконка `#1D5FE0`, фон `rgba(255,255,255,0.92)`, тень `rgba(42,127,255,0.35)` | «Наверх» |

### T1. Баннер «Смета для клиента» на главной
- Где: `src/app/(tabs)/index.tsx`, под блоком заголовка, **над** «Загрузить прайс / Весь каталог».
- Вид: плашка радиус 14, фон `maxTint`, контур `maxTint`; слева 📄, текст:
  **«Смета для клиента»** / мелко «Техника с вашей наценкой + работы → PDF»;
  справа кнопка-пилюля **«Создать →»** с градиентом `max`, белый текст 800.
- Нажатие → `/estimate`.
- Приёмка: баннер виден без прокрутки на 360×800; цвета совпадают с сайтом.

### T2. Плашка сметы в корзине
- Где: `src/app/(tabs)/cart.tsx` (`estimateButton`, сейчас бледно-оранжевая).
- Сделать **тот же вид, что T1** (компактнее: значок 1.3×, подпись «Ваша наценка + работы → PDF клиенту»,
  кнопка «Создать →»). Лучше вынести в общий компонент `EstimateCta` и использовать в T1 и T2.

### T3. Экран сметы — функции как на сайте
Файл `src/app/estimate.tsx`, логика `src/features/estimate/*`.
1. **Своя техника сметы** (не равна корзине):
   - при открытии, если список пуст, — подставить позиции из корзины;
   - поле **«🔍 Найти технику: модель, бренд, BTU…»**: поиск по видимым товарам каталога
     (бренд + серия + модель + описание + «N btu», все слова должны совпасть), до 12 результатов
     с ценой опта; нажатие добавляет 1 шт.;
   - у каждой позиции: «−», количество, «+», «✕»; на мобиле цена-итог слева, кнопки справа второй строкой;
   - если в корзине есть позиции, которых нет в смете, — кнопка «🛒 Добавить из заявки (N поз.)».
2. **Имя позиции**: «Бренд Модель», но без дубля, если модель уже начинается с бренда
   (было «DAICHI DAICHI ICE35…»).
3. **Работы**: у своих работ — кнопка ✕ (удалить); новая своя работа сразу в фокусе для ввода названия.
4. **Хранение** (как на сайте):
   - техника сметы живёт только в памяти (до перезапуска приложения), в AsyncStorage **не сохраняется**;
   - `estimateSettingsStorage` хранит наценку, работы (цены/названия/свои), исполнителя;
   - при загрузке настроек **количества работ сбрасываются**: `install` = 1, остальные = 0.
5. Расчёт не менять — он уже совпадает с сайтом (`clientUnitPrice`, `computeEstimate`).

### T4. Кнопки внизу сметы
- Блок итогов как сейчас (Оборудование / Работы / Итого клиенту / «Ваша наценка … (в смете не видна)»).
- Под ним:
  1. **«📤 Отправить клиенту PDF»** — во всю ширину, градиент `max`, белый текст.
     Действие: нативный шаринг PDF (`shareEstimatePdf`, expo-sharing) — уже работает.
  2. Ряд из двух кнопок: **«Скачать PDF»** (`pdf`, красная) и **«Скачать Excel»** (`excel`, зелёная),
     у обеих иконка файла со стрелкой вниз.
- «Скачать PDF» = текущее «Сохранить PDF в «Загрузки»». Состояния загрузки: «⏳ PDF…», «⏳ Excel…».
- Кнопки неактивны, пока в смете нет техники.

### T5. Экспорт сметы в Excel (новое)
- Тот же макет, что на сайте (`_estXlsxBlob` в `estimate.js`):
  - колонки: № 4.5 · Наименование 40 · Кол-во 7 · Ед. 6 · Цена 12 · Сумма 13 (символы), сетка скрыта;
  - строка 1: «СМЕТА» (20 pt, жирн.) + «от ДД.ММ.ГГГГ» (12 pt, серый), высота 34;
  - исполнитель/телефон — серая плашка `#F2F4F8`, полоса слева `#94A3B8`;
    заказчик/объект — тёплая `#FFF4DE`, полоса `#F59E0B`; подпись жирная, значение в объединённых B:F;
    высота строки по длине текста (≈15 pt на строку);
  - разделы «Оборудование и материалы», «Работы»: заголовок `#D97706` 13 pt, шапка таблицы `#F2F4F8`,
    строки высотой ≥20, чередование `#FAFBFC`, суммы `=C*E`, «Итого:» `=SUM(...)`,
    **формулы с готовыми значениями** (иначе мобильные просмотрщики показывают пустые ячейки);
  - «ИТОГО К ОПЛАТЕ» — плашка `#FFF4DE`, сумма 14 pt `#D97706`; внизу примечание о сроке 7 дней;
  - формат денег `#,##0" ₽"`, A4 по ширине страницы.
- Реализация на выбор разработчика: `exceljs` (нужны полифиллы `buffer`/`stream` для RN)
  или генерация XLSX своим XML-писателем; файл `smeta-ГГГГ-ММ-ДД-ЧЧММ.xlsx` сохранять в «Загрузки»
  тем же способом, что PDF.
- Приёмка: файл открывается в Excel/Google Таблицах/просмотрщике Samsung без обрезанных строк,
  суммы видны без пересчёта.

### T6. Кнопка «Наверх» в каталоге
- Где: `src/app/(tabs)/catalog.tsx` (есть `listRef` у `FlatList`).
- Появляется, когда прокрутили > 200 px (`onScroll`, `scrollEventThrottle={16}`), плавно (opacity + сдвиг).
- Вид: круг 58×58, слева снизу (left 14, над таб-баром с отступом ~16), фон/контур/цвета — токен `up`;
  внутри иконка стрелки вверх 20 px и подпись **«Наверх»** 9–10 pt, жирная; нажатие — scale 0.94.
- Действие: `listRef.current?.scrollToOffset({ offset: 0, animated: true })`.
- Не перекрывает таб-бар, всплывашки «Добавлено в заявку» и кнопки карточек.

### T7. Контраст «стеклянных» плашек
- Правило с сайта: у полупрозрачных плашек фон-тон не слабее ~0.2/0.1 и контур ~0.55–0.6, иначе на
  светлом фоне их не видно. Пройтись по главной и корзине (плашки, чипы фильтров, статусы) и
  поднять контраст там, где плашка сливается с фоном.

### T8. Шапка главной
- Проверить на ширине 320 и 360 dp: «Войти/Профиль» и «Заявка» помещаются, «Заявка» не уходит за край
  (с бейджем количества, если он есть/будет). Длинное имя — с многоточием.

### T9. Выпуск
- Поднять версию (`app.json` + `android/app/build.gradle`), собрать APK, опубликовать через
  `scripts/deploy_apk.py` (обновление обязательное по умолчанию).
- Проверка на реальном Android (в т.ч. Samsung): смета → «Отправить клиенту PDF» → Telegram / WhatsApp /
  Max / почта получают **PDF-файл**; «Скачать PDF/Excel» кладут файлы в «Загрузки».
