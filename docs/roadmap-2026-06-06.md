## Cross-cutting blockers (apply to almost everything)

1. **RU geo-block of Expo Push.** `exp.host` (Google Cloud) returns 403 to Russian
   IPs. Getting a token needs VPN on the device; sending from the **server (in RU)**
   via `sendUserPush()` almost certainly 403s too (untested — verify). Real RU
   delivery needs **RuStore Push (VK)** or a direct FCM/APNs server send from
   non-RU infrastructure. This affects the admin panel, publishing, and iOS.
2. ✅ **Release keystore — SOLVED (2026-06-06).** Generated our own release keystore
   (`android/app/release.jks`, alias `splithub-release`); the release variant signs
   with it. ⚠️ Still must keep an **offline backup** of `release.jks` +
   `keystore.properties` (losing it = can't update the app).
3. ✅ **Reproducible build — SOLVED (2026-06-06).** node_modules fixes are now in
   **patch-package** (`patches/` + `postinstall`); `android/` overrides + signing
   config are **committed to git** (bare workflow) so they survive `npm install`.
   A full `assembleRelease` was verified GREEN.

## Q2 — Publishing the app (cloud link / RuStore / Google Play)

**Prerequisite for all:** release keystore (#2) + reproducible build (#3).

| Option | Pros | Cons |
|---|---|---|
| A. Cloud link (host signed APK, share URL) | Instant, free, full control, good for your own B2B clients | "Unknown sources", Play Protect warning, **no auto-updates** |
| B. RuStore | Right store for RU; **RuStore Push** solves the geo-block; light moderation | Android only |
| C. Google Play | Global reach | $25 one-time, needs AAB, stricter review, RU access limits |

**Recommended order:**
1. Release keystore + reproducible build.
2. Signed APK → **cloud link for existing clients** (fast start).
3. **RuStore** (RU audience + push provider).
4. (optional) Google Play.

**RuStore steps:** register developer → create app → upload signed APK/AAB →
listing (icon ✅, screenshots, description, privacy policy ✅
[`privacy-policy-ru.md`](./privacy-policy-ru.md), support contact) → moderation → publish.

**Google Play steps:** Play Console ($25) → create app → upload **AAB** → listing +
Data Safety form + content rating → review → publish.

## Q3 — iOS

**No re-development** — the same Expo/RN code is the iOS app. Work is tooling + Apple config.
- **Requires macOS to build** (impossible on Windows) + **Apple Developer Program $99/year**.
- Build without owning a Mac: **Codemagic** (free Mac-mini minutes), EAS (paid/quota), or a rented/borrowed Mac.
- **Push on iOS:** APNs key `.p8` instead of FCM. Same RU Expo-Push constraint applies (blocker #1).
- **Route:** Apple Developer → build on macOS (Codemagic) → APNs key → **TestFlight** → App Store review.
- RuStore is Android-only; iOS distributes only via the App Store.

The app.json already has `ios.bundleIdentifier = ru.splithub.mobile` and the icon, so iOS is buildable as-is.
