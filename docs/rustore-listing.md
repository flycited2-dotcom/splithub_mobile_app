## Карточка приложения

**Название:** СплитХаб

**Краткое описание** (subtitle, до ~80 символов):
> Оптовый каталог кондиционеров и расходников для монтажников

**Категория:** Бизнес (альт.: Покупки)
**Возрастной рейтинг:** 0+ / 3+ (контент без ограничений)

**Полное описание** (можно копировать целиком):
```
СплитХаб — мобильный оптовый каталог климатической техники для монтажников и
установщиков кондиционеров. Заказывайте сплит-системы, медную трубу и расходники

Только для профессиональных монтажников и B2B-клиентов. Работаем в Симферополе и
```

## Графика (подготовить перед загрузкой)
- **Иконка:** 512×512 PNG. Исходник: `assets/images/icon.png` (ресайзнуть до 512×512).
- **Скриншоты телефона:** минимум 2–3 (RuStore: от 320 px по меньшей стороне,
  обычное соотношение 9:16). Снять на устройстве с установленным приложением:
  главный каталог, карточка товара, корзина/заказ, экран статусов/уведомлений.
- (опц.) Баннер для витрины, если попросит консоль.

## Порядок действий в RuStore Console (console.rustore.ru)
1. Войти (VK ID / Госуслуги), выбрать тип аккаунта **ИП**, ввести реквизиты выше,
   подписать оферту (может потребоваться подтверждение через Госключ/ЭП).
2. Создать приложение → загрузить `app-release.apk`.
3. Заполнить карточку: название, описания, категория, возрастной рейтинг,
   privacy policy URL (https://splithub.ru/privacy/), иконка, скриншоты.
4. Контакты разработчика: email/телефон выше.
5. Отправить на модерацию. После одобрения — публикация.

## Заметки
- RuStore Push (VK) на будущее снимает гео-блок регистрации Expo push-токена в РФ
  (см. mobile-handoff-memory) — отдельная интеграция, не нужна для первой публикации.
- versionCode для будущих обновлений увеличивать (1 → 2 → …), подпись тем же keystore.
