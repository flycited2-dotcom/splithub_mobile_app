# Дорожная карта: от PWA к Android-приложению

## Этап 0 — тесты PWA (сейчас)
- Разместить папку `spina-quest/` на HTTPS (GitHub Pages / Netlify). Установить на телефон ребёнка как PWA.
- 1–2 недели реальных занятий. Собрать: экспорт JSON из родительского раздела, замечания по формулировкам, по длительности, где ребёнок теряет интерес.
- Показать `data.js` ортопеду/физиотерапевту: он правит тексты, секунды, флаги `sides`/`breath`, добавляет свои упражнения.

## Этап 1 — Android-обёртка (1–2 недели)
Вариант А (быстрый): **Capacitor** — та же веб-версия внутри нативного контейнера.
- `@capacitor/local-notifications` — ежедневное напоминание в выбранное время («Герой ждёт миссию!»).
- `@capacitor/haptics` — вибрация; `@capacitor/text-to-speech` — стабильный русский голос вместо Web Speech.
- `@capacitor/preferences` / SQLite — хранение вместо localStorage (не чистится системой).
- Play Console: возрастная категория «для семей», политика конфиденциальности (данные только на устройстве).

Вариант Б (полный): **Expo / React Native** — в этом репозитории уже есть Expo-инфраструктура (EAS, Android bare-проект). Переносим экраны 1:1: `data.js` остаётся общим модулем, логика таймера/наград — в хуках.

## Этап 2 — контент и «лечебный слой» (после согласования с врачом)
- Профиль ребёнка: возраст, тип дуги (например, грудная правосторонняя), ограничения — заполняет врач.
- Асимметричные дозы: `sides: {L: 60, R: 90}`, направление коррекции, дыхание в вогнутую сторону (Schroth-принципы) — только по назначению.
- Программы на 4–8 недель с прогрессией (больше секунд, сложнее вариант) вместо фиксированных 15 миссий.
- Видео/GIF реальных демонстраций вместо схематичных фигурок (снять с инструктором).

## Этап 3 — вовлечение
- Персонаж, который «растёт» и получает костюмы за уровни (аватар из слоёв SVG).
- Еженедельный «босс-квест» и сезонные события.
- Награды в реальной жизни, настраиваемые родителем («10 звёзд = поход в кино»): родитель задаёт, ребёнок видит прогресс к цели.
- Совместный режим: родитель занимается вместе (две галочки за день).

## Этап 4 — контроль качества движения
- Камера + MediaPipe Pose (на устройстве, без отправки видео): проверка симметрии плеч/таза в стойке, подсчёт повторов моста/приседа, подсказка «плечи ровно».
- Фото осанки раз в месяц в одинаковой позе — родителю и врачу для динамики (только локально/по явному согласию).

## Этап 5 — врач и данные
- Экспорт PDF-отчёта за месяц (минуты, серия, отметки боли по упражнениям).
- Опциональная синхронизация с кабинетом врача (сервер, согласие родителя, 152-ФЗ).

## Технические заметки
- Голос: на Android Web Speech в WebView работает нестабильно — в нативной версии использовать системный TTS.
- Таймер уже устойчив к сворачиванию (метки времени), но в нативной версии добавить foreground-service/keep-awake на время занятия.
- Все строки интерфейса — на русском в разметке; при необходимости локализации вынести в словарь.
