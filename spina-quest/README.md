# Спина: Квест — v2 (PWA-прототип)

Интерактивные ежедневные занятия для осанки ребёнка: 15 миссий, герой, опыт и уровни,
звёзды, достижения, серия дней, голосовые подсказки, родительский раздел с PIN.

## Запуск
- Локально: открыть `index.html` в браузере (Chrome / Safari).
- Для теста: `npx http-server -p 8765 .` → http://localhost:8765
- На телефон: выложить папку на любой HTTPS-хостинг → «Добавить на главный экран».

## Файлы
| Файл | Назначение |
|------|------------|
| `index.html` | разметка всех экранов |
| `styles.css` | оформление |
| `data.js` | **контент**: миссии, упражнения, герои, уровни, достижения, фразы, красные флаги |
| `app.js` | логика: состояние, таймер, звук/голос, награды, родительский раздел, SVG-фигурки |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA |
| `tools/e2e.js` | автотест на Playwright со скриншотами |
| `docs/ANALYSIS.md` | разбор исходного MVP и список изменений |
| `docs/ROADMAP_ANDROID.md` | план перехода к Android-приложению |

## Тест-режим
Родитель (👪) → Настройки → «Демо-режим» — таймер в 20 раз быстрее.

## Медицинская граница
Приложение содержит общеукрепляющие симметричные упражнения низкой интенсивности.
Оно не диагностирует и не лечит сколиоз и не подбирает направление коррекции дуги.
Индивидуальные сколиоз-специфические упражнения назначает детский ортопед / физиотерапевт.
